Project Name: EasyResume

Description:
EasyResume is an AI-powered resume builder.

Features:
1. Resume creation form
2. Multiple resume templates
3. Live resume preview
4. AI assistant on the right side

6. Interactive checklist
7. PDF download
8. Resume storage
9. Responsive design
